# 织忆 WaveMemory

本仓库只用于发布织忆（WaveMemory）的安装包，不包含任何源代码。

## 下载

在 [Releases](https://github.com/nexusonelw/weave_memory_public/releases/latest) 页面下载最新版本：

| 平台 | 文件 |
| --- | --- |
| macOS（Apple 芯片） | `wavememory-<版本>-mac-arm64.dmg` |
| macOS（Intel 芯片） | `wavememory-<版本>-mac-x64.dmg` |
| Windows x64 | `wavememory-<版本>-windows-x64.exe` |
| Android | `wavememory-<版本>-android.apk` |

桌面端会自动检查这里的新版本，也可以在「设置 → 关于」中手动检查更新。
